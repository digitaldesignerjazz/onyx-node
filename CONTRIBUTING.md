# Contributing to Onyx Node

1. Read [docs/PUBLIC_BOUNDARY.md](docs/PUBLIC_BOUNDARY.md) first.
2. Open an issue before large scope.
3. Small, reviewable commits on a branch. Pull requests against `main`.
4. No force-push on `main`.
5. Do not commit live keys, overlay tokens, wallet seeds, skilllogin state or private persons.
6. QNET / Wizard Q remain **Proposed** unless a public spec in this repo says otherwise.

Security reports: [SECURITY.md](SECURITY.md).

# Security

Report vulnerabilities privately. Do not open a public issue that contains:

- overlay setup keys or auth keys
- wallet seeds, mnemonics, private keys
- skilllogin dumps or private ledgers
- household or personal coordinates

Preferred path: GitHub private vulnerability report on this repository,
or an email to the operator identity already used on public Esslinger & Co. surfaces.

This seed stores **no private key material**. Identity in `state/identity.json`
is a public node label plus a generated hex id. Future signing keys stay local.

# Public boundary

Onyx Node is a **public prototype**. Publish interfaces, schemas with
placeholder parameters, and operator-safe docs.

## Publish

- Architecture sketches and proposed interfaces
- Example config (`config/onyx.example.toml`)
- Heartbeat / pulse schema without live fingerprints
- Contributor and security policy

## Do not publish

- skilllogin state or private swarm memory
- Mesh setup keys, overlay tokens, wallet seeds
- Private repository contents
- Real-person names outside the operator public identity
  Esslinger & Co. / digitaldesignerjazz
- Household or sanctuary coordinates

Private OS lineages (avalon-os, lumiaos, ElysiumOS) may be named as
lineage only, not mirrored.
